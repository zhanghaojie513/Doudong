## 当前状态（2026-10-23）

- 候选设计已按技术评审修订；公共 API 仍为 experimental，M0 尚未完成总体验收。
- 实际工程为 6 个产品项目 + 1 个测试项目；Telemetry 未建，产品项目无外部 NuGet 引用。Agent/Ai/Mcp/Acp 尚无业务实现，CLI 仅输出占位文字。
- Kernel 已实现静态插件生命周期协调、必需依赖阻塞/恢复、显式失败重试、锁外清理、停用取消传播与迟到注册拒绝。服务注册按插件/代次暂存，成功激活时原子发布，失败/停用/销毁时丢弃；Active 后不再接受新增注册。
- 新增显式服务调用租约：`Resolver.Resolve<T>` 返回代次绑定引用，`InvokeAsync` 原子获取在途租约；停用先封闭受影响批次的新调用并取消，等待实际调用结束后才清理。批次按激活序逆序清理，消费者先于提供方；超过 `DrainTimeout` 未排空则标记失败、不执行清理并需重启宿主。旧引用在重激活后仍不可用；`Services.Resolve` 仍是未跟踪的过渡入口。
- .NET SDK 10.0.402 可用；完整解决方案 Release 构建通过（0 警告、0 错误），84 项内核行为测试全部通过（0 跳过）。测试启用 `--blame-hang-timeout 90s`，未触发挂起超时。尚未验证 pack，也未通过完整 M0 反例集。
- 首个提交 `5c1bbe5` 已推送至 [GitHub 仓库](https://github.com/zhanghaojie513/dougong)。本阶段代码与状态文档改动尚未提交、推送。
- [前沿调查](frontier-roadmap.md)与[未来迭代路线](iteration-roadmap.md)已建立；后者面向 M3 之后，不作为当前 M0 已完成的证据。

## 约定

- 当前 API 全部 experimental，编译契约详细定义以 architecture.md 为准，design.md 保持摘要和决策，避免复制多份接口后漂移。
- 实现与其行为测试一起交付；未运行、失败、未覆盖的检查必须如实记录，文档勾选不替代测试结果。
- 原工期和桌面周数是未验证估算，按 PoC 和单人产能重估，不当作并行人力或交付承诺。
- M1 验收后再用 CLI 辅助后续开发；自用不能替代故障与独立任务验证。
